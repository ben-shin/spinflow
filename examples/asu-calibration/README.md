# ASU calibration walkthrough files

Follow the matching [tutorial](../../docs/tutorials/asu-calibration.md) from the same source revision. Its installed product is pinned public0.3.0b3; these later example files are not claimed to exist in the original b3 source archive.

Run each whole-file stage with `sh` as shown in the guide: setup, process/diagnostics, then a separately resumed analysis stage and session/replay. The diagnostic-only session file is an alternative after phase refusal. Python helpers run only with the installed interpreter's `-I -B` flags. No acquired data or vendor software is included.
