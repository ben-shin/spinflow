## Reproducibility and preservation

1. Record candidate source tree hash and package/native/installer version before building. Build Linux wheel and sdist from that exact tree. Install outside the source checkout and record hashes, environment and `doctor` output.
2. Reuse archived v0.2.0 saved recipe/native artifacts read-only; validate hashes before load/replay. Write all S18 outputs under new `.artifacts/readiness/` paths. Never edit old S15/S16/S17 seals or measured files.
3. For actual full protein workflow, use the prior hash-pinned input and fixed 14-operation recipe; compare full samples, axes, dtype, quadrature, loss reports and processing history. Separate expected package/native version or provenance metadata changes from mathematical changes; do not relax numerical tolerances or replace old golden hashes without explaining the difference.
4. The private Linux validation environment must use a new S18 overlay and logs. The old closed S17 VM and its backing evidence are read-only. If comparing performance, preserve the declared one CPU/WHPX setting and identify virtualized hardware. A fresh artifact smoke and complete real workflow have priority over repeating expensive 3D/4D benchmarks when numerical block code has not changed.
5. GUI automation is evidence of behavior, not human usability acceptance. Record untested desktop, GPU/Wayland, independent researcher and holdout acquisition scope explicitly.

## Review and decision

The integration owner freezes one candidate source/artifact revision before independent review. Three jurors inspect correctness/evidence, robustness/failure cases, and usability/documentation; a separate judge adjudicates requirements and findings. Each requirement is PASS, FAIL or UNVERIFIED against exact evidence. The task-wide review reserve is three jurors plus judge, with at most two integrated post-review repair rounds. Any edit after freeze creates a new candidate revision and requires relevant retesting. Root coordinates acceptance and publication; no tag, release, user-facing stable claim or researcher contact is authorized by this protocol.
