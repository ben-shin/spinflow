# Validation and limits

SpinFlow's processing contract is described in [numerical conventions](numerical-conventions.md), [data model](data-model.md), and [format profiles](formats.md). The test suite includes independent direct-DFT and analytical fixtures, native versus NumPy comparisons, codec failures and read-back checks, CLI workflows, and optional GUI integration.

The historical stage sections below describe evidence available at their own checkpoints. The later 0.3.0b1 experimental beta has a bounded [single-case NMRPipe and end-user application comparison](laboratory-workflow-results.md) and separate [installed candidate evidence](v1-candidate-results.md); neither establishes broad parity or alters those historical checkpoints.

## Controlled Agilent and difficult-spectrum evidence

The [Varian/Agilent protocol](real-varian.md) compares two public acquired cases and their independent stored NMRPipe references using fixed quadrature signs, processing and explicit coordinate orientation. The data are fetched to an ignored cache; no redistribution permission is assumed. This is evidence for the declared profiles and recipes, not general vendor or NMRPipe parity.

One stored processed protein spectrum was examined using five predeclared source boxes and a separate off-region noise selection. Under the fixed six-MAD threshold and four-point separation, the masked and default noise estimates each produced 57 candidates and recovered all five boxes. This does not demonstrate a recovery improvement. The reference-linear baseline volumes were checked against an independent numerical calculation on the stored array; they are not independent biological volume truth or concentrations. The selected reference samples must be assessed as signal-free.

Automatic phase on the stored real-only reference is unavailable because it has no quadrature channels. An initial full-quadrature trial incorrectly coupled line handedness to reflected physical coordinates; that defect was corrected. Repeating the same fixed-anchor trial with corrected handedness still refused with `AUTOPHASE_INSUFFICIENT_LINES` and zero accepted lines. Three rejected fits had relative residuals approximately 0.0805, 0.0628 and 0.0701, above the unchanged 0.04 limit. The restricted positive separable line model was not retuned. This is not a general protein or mixed-lineshape phasing capability. The protocol and source hashes are executable in `tools/validate_public_hard_spectra.py` and `tests/io/test_hard_spectra_public.py`.
