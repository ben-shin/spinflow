# Processing candidate status

**October 30, 2026 preparation checkpoint:** The previous published **v0.2.0 experimental prerelease** is immutable. Version `0.3.0b1` is the distinct experimental beta under publication review, based on clean source baseline `2e632f075f7b7822345b0a3e9f8d27980e63001a`. It is not a 1.0 release or a stable scientific-support claim. The [support registry](../compatibility/support.json), [proposed contract](support-contract.md), [candidate protocol](v1-candidate-protocol.md) and [evidence status](v1-candidate-results.md) define the scope and evidence.

The source includes controlled 1D/2D raw processing, narrow real NMRPipe/UCSF interchange, bounded 1D/2D analysis, and a separate experimental native schema-1 HDF5 block path for selected 1–4-axis numeric processing. A previously studied Varian protein case has a selected NMRPipe 13 comparison and NMRDraw/Sparky reopening. The 3D/4D acquired examples have relative Hz coordinates and no original processed reference. Neither comparison establishes general scientific or speed parity.

The v3 code diagnostic implemented ordered GUI recipe editing, applied-phase retention, a saved session, and calibrated bounded-region analysis of a full 8,388,608-point acquired result. Its Linux CPython 3.12 installed suite and actual automated X11 desktop workflow passed on one acquired case, including save/reopen and exact CLI replay. NMRDraw 13 reopened the current ft2 export, and Sparky 3.115 reopened the current UCSF export and displayed five fixed regions; independent decoders matched the selected numeric outputs and prior controlled grids. A hash-verified previous-v0.2.0 synthetic recipe/native pair also replayed within its predeclared tolerance. The exact source/package hashes and limits are in the [evidence status](v1-candidate-results.md). Publication metadata changes require a new source freeze and artifact check; this selected evidence does not establish broad compatibility or human acceptance.

**Pending before any 1.0 decision:** independent acquisitions and scientific checks for every promoted profile, exact-binary performance/resource acceptance on a supported user machine, actual desktop and independent researcher workflows, installed candidate upgrade/backward-load evidence, and independent release review. Assignment projects, NEF and general NMRPipe parity are outside the proposed scoped processing contract.
