# Current implementation scope

This increment targets synthetic 1D/2D workflows and one controlled public Bruker raw 1D path through the headless CLI and optional Qt workbench. It includes explicit recorded-delay digital-filter correction, explicit frequency referencing, window, zero fill, FFT, manual phase, crop, reverse, transpose, native storage and declared interchange profiles. A bounded 1D complex automatic phase estimator, signed 1D/2D peak detection and relative region integrals produce digest-linked reports; optional Matplotlib figures do not become a core dependency. The GUI can save a native source plus a strict CLI recipe for replay of the last applied processing result. The [real-data and analysis guide](real-bruker-and-analysis.md), [Linux user-testing guide](linux-user-testing.md), [roadmap](../ROADMAP.md) and [compatibility inventories](../compatibility/functions.yaml) retain the practical and broader future scope.

The synthetic complex/States mathematical model uses fully sampled axes. One public Bruker 1D acquisition with positive recorded `GRPDLY` has a bounded correction/archived-position check; unknown or zero delay, implicit DSP lookup, raw 2D and broader vendor semantics remain unsupported. NUS reconstruction, 2D automatic phase, automatic baseline correction, LP, deconvolved fitting, NEF and script translation remain visible future work. Unsupported requests fail. This single public acquisition does not satisfy the broader laboratory workflow exit of Milestone 1 because independent consumer reopening, NMRPipe parity and quantitative validation remain open.

Native means no NMRPipe subprocess; it does not mean every operation executes in C++. The declared Bruker correction and analysis are Python/NumPy/SciPy implementations, while the selected C++20/PocketFFT backend executes the FFT. Legacy numerical parity, NMRPipe benchmarks, real user-failure regression, all-format fidelity and broader platform installation claims remain blocked until evidence exists. The archived TopSpin check is independent for eight peak positions only, not a general consumer or amplitude/phase/integral reference.
