# Numeric data contract, schema 1

This is the restricted first implementation contract, not full NMRPipe compatibility.

`Axis(id, size, role='spectral', domain='time', label='', nucleus=None, unit='s', start=0, step=1, observation_mhz=None, reference_ppm=None, reference_hz=0, encoding='complex', time_origin_seconds=0, dwell_seconds=None, acquired_size=None)` is immutable. IDs are unique; nuclei are labels, never identities. Role is `spectral` or `series`. Domain is `time`, `frequency`, or `index`; series axes cannot be Fourier transformed. Coordinates are `start + step * index`; frequency uses Hz, time seconds, and index axes arbitrary declared units. Ppm requires observation MHz and an explicit reference: `reference_ppm + (frequency_hz-reference_hz)/observation_mhz`. Display direction never changes data silently.

`Dataset(data, axes, complex_axes=(), metadata={}, provenance=[])` stores real float32 or float64 channels, shape `(2**q, *physical_axis_sizes)`. Bit k of the channel index is the imaginary quadrature of `complex_axes[k]`. With complex_axes `(t1,t2)`, channels are RR, IR, RI, II (first letter t1). Every channel is retained. Physical transposition changes axes/storage order but keeps this ID-based channel mapping; it never treats channels as physical dimensions. Datasets copy inputs and expose a read-only numeric array; operations return new datasets.

Axis `acquired_size`, `dwell_seconds`, and `time_origin_seconds` preserve acquisition information through padding and Fourier transformation. First-point scaling and phase are explicit operations/parameters, never inferred from a half-dwell origin. Metadata is JSON data and preserves uninterpreted source fields. `sampling` metadata other than explicit `fully_sampled` is rejected by transforms until reconstruction exists: missing samples must not become measured zeros. Vendor quadrature and digital-filter handling are limited to the declared, tested profiles; synthetic `states` alone is not certification of a vendor encoding.

Frequency orientation and ppm referencing are explicit calibration choices; raw acquisitions do not supply a guessed chemical-shift anchor. The optional `frequency_scale` on a reference operation reflects coordinates when set to -1 without changing the data. See [numerical conventions](numerical-conventions.md).

The reserved metadata field `quadrature_index_orientation` maps each current frequency-domain complex axis ID to integer +1 or -1, describing the quadrature line handedness in sample-index order. It is separate from the physical-coordinate direction. A forward FFT sets +1 for that axis, a sample reverse flips its sign, and inverse FFT removes it; referencing, cropping and transposing preserve it. A declared map must cover exactly the current frequency complex axes. When the field is absent on an older dataset, the resolver uses axis-step signs and corrects for recorded reference reflections since the last FFT. Nondefault resolved orientation is included in analysis digests, so older masks for reflected datasets may need regeneration. Automatic-phase reports expose the resolved orientation.

When omitted on construction, acquired_size defaults to initial size and time_origin_seconds to the initial time-axis start. A crop changes current start without changing those acquisition fields. The additional optional `transform_time_origin_seconds` records the time-grid start consumed by FFT so inverse transformation can restore a cropped time grid without replacing its original acquisition origin.

`to_metadata()` and `from_metadata(data, metadata)` serialize schema_version, axes, complex_axes, metadata and provenance. Readers must reject unknown versions and preserve fields or report unsupported content. Native HDF5 must preserve all channels. Limited exports require explicit real projection/loss reporting and cannot claim lossless interchange.
